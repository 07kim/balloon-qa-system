# Google Apps Script (GAS) ＆ スプレッドシート セットアップ手順書

「インタラクティブ・バルーンQ&Aシステム」をGoogleスプレッドシートと連携させる手順です。

---

## 1. スプレッドシートの作成
1. Google ドライブで新規の Google スプレッドシート を作成します。
2. 1行目（ヘッダー行）に以下の項目名を設定してください（スクリプト実行時にも自動生成されます）。

| 列 | 項目名 | 内容 |
|:---|:---|:---|
| A列 | **ID** | 一意のID文字列（例: `q_1700000000000_123`） |
| B列 | **キャラクター** | 選択されたキャラクター番号（1〜10） |
| C列 | **質問内容** | 送信された質問テキスト |
| D列 | **回答内容** | 運営が入力した回答テキスト |
| E列 | **タップ数** | タップされた合計回数（初期値 `0`） |
| F列 | **消滅フラグ** | タップ数が20に達すると `TRUE` に変更 |
| G列 | **送信日時** | ISO形式の日時 |

---

## 2. Google Apps Script の配置
1. スプレッドシートのメニューバーより **「拡張機能」 ➔ 「Apps Script」** を開きます。
2. もともと入っている `Function myFunction() {}` を削除します。
3. このリポジトリの [`gas/Code.gs`](file:///Users/mayugeyasai/個人/制作物/意見/gas/Code.gs) の内容をすべてコピーし、エディタ上に貼り付けます。
4. プロジェクト名（例: `Balloon-QA-Backend`）を入力し、保存（Ctrl+S / Cmd+S）します。

---

## 3. ウェブアプリとしてのデプロイ
1. エディタ右上にある **「デプロイ」 ➔ 「新しいデプロイ」** をクリックします。
2. 歯車アイコンの「種類の選択」から **「ウェブアプリ」** を選択します。
3. 以下の通り設定します：
   - **説明**: `Balloon QA API v1`
   - **次のユーザーとして実行**: `自分 (YOUR_EMAIL@gmail.com)`
   - **アクセスできるユーザー**: `全員` (重要: 参加者端末から認証なしで通信できるようにするため)
4. **「デプロイ」** ボタンを押します。
5. アクセス承認が求められた場合は、「アクセスを承認」をクリックし、ご自身のアカウントを選択して進めてください。
6. デプロイ成功時に表示される **「ウェブアプリ URL」** (例: `https://script.google.com/macros/s/AKfycbx.../exec`) をコピーします。

---

## 4. Webアプリ画面でのURL登録
1. ブラウザで [admin.html](file:///Users/mayugeyasai/個人/制作物/意見/admin.html)（運営管理画面）を開きます。
2. ヘッダー右上の **「API・GAS設定 ⚙️」** ボタンをクリックします。
3. コピーした 「ウェブアプリ URL」 を貼り付け、**「設定を保存」** ボタンを押します。
4. これにより、参加者画面（`index.html`）および運営画面（`admin.html`）の両方でスプレッドシートとの双方向リアルタイム同期が開始されます。

> **NOTE:** GAS Web App URLを設定していない状態では、ブラウザの `LocalStorage` を利用したローカルモックモードとして自動的に動作するため、ローカル環境でも全ての動作確認が可能です。
